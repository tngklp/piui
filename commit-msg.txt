fix(editor): selection highlight, numeric fields, and repo hygiene

- The editor selection was invisible because CodeMirror's base theme sets the
  drawn selection with a five-class selector, and a theme targeting the short
  `.cm-selectionBackground` loses to it and gets the base theme's near-black
  #222. Match the full path, and mix the wash from the accent so it is actually
  visible. The active line is translucent now for the same reason: an opaque
  line background paints over the selection layer.
- Numeric settings fields clamped on every keystroke, so typing 16 into a 10-24
  range was impossible: 1 clamped to 10, the field was rewritten, and the 6
  landed after it. New NumberField keeps a draft and commits on blur or Enter;
  used for font size, auto save delay and terminal scrollback.
- Monitor: GPU card moved above System.
- Models tab: section headings, provider cards on the panel surface, the
  provider id as the card title, and a Hosted API / Local chip. Installed
  packages get the same treatment with an empty state and the bare package name
  over its install spec.
- Icon pack buttons preview src/ plus python, js, ts, c#, c++, java, rust, lua,
  go, json, yaml, image, markdown, .gitignore and .dat; added a .dat mapping to
  the Catppuccin pack.
- Attachments accept text files as well as images: text is inlined as a file
  block, images stay image blocks. Binary files such as PDFs are refused with a
  reason rather than inlined as noise.
- resources/ renamed to assets/. The app icon and the icon packs are generated,
  so they are gitignored and rebuilt by `npm run assets` in predev and
  pretypecheck. scripts/ stays committed, because those generators are source.
- Comprehensive README covering features, install, development, architecture,
  configuration, releasing and troubleshooting.
